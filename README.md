# Project Lyrics

A Python-based terminal music player that displays colorful, synchronized lyrics with a live playback timer and progress bar.

### Features
- Colorful terminal lyrics
- Live playback timer and progress bar
- Custom lyrics and timestamps
- Local audio playback

### Built With
- Python
- Pygame

### Usage

Install dependencies:

```bash
python3 -m pip install -r requirements.txt
```

Run the player:

```bash
python3 lyric_player.py
```

Customize the audio file, title, and lyrics in `lyric_player.py` to use a different song.

**Note:** Lyrics and timestamps must be configured manually.
